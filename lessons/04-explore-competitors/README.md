# 04 Explore competitors

Goal: run your agent on a list of competitor sites. One browser session per site, a few in parallel.

Input is `competitors.txt`, one URL per line. Use the example list (specialty coffee roasters) or write your own.

You'll learn:
- running sessions in parallel and what limits apply
- what a block looks like and how the agent should react
- what it costs: browser minutes and tokens per site

Bonus: find the competitors yourself with Zyte API search and article extraction, no browser needed for that part.
